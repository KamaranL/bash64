## Installation and Usage

### Dependencies

- base64
- bash `>=3`
- cat
- date
- perl `>=5`
- realpath
- sha256sum

### Local Machine

You can easily install the latest, stable version by executing the command below:

```bash
bash <(curl -s https://gist.githubusercontent.com/KamaranL/e7b37e4efdfff77f281e6a9194ec2456/raw/install_stable.sh) bash64
```
